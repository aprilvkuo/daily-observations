## 科技与产业

### Agent从“全装工具”转向按需检索
Google在11月19日发布Gemini API Tool Retrieval预览：大型工具库不再每次发送全部Schema，而可以按任务检索并加载。潜在好处是减少上下文Token和工具误选；但检索漏召回可能造成失败，需用工具Recall@k、任务完成率、p95延时、每成功任务成本进行A/B测试。[Google技术博客](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)

### AI算力景气与资本回报是两个不同问题
NVIDIA FY2027 Q3收入同比增长103%，不证明采购其芯片的所有云公司都能收回Capex。应按“芯片采购→机房上线→利用率→收费→利润→扣除设备更新与折旧后的现金回报”建立链路，对GPU定价、算力供给、芯片寿命和客户集中分别设Bear/Base/Bull情景。

### 研发Agent更需要环境复用与明确失败归因
长任务工程的首要指标不是模型输出Token数，而是**有效实验/全部尝试、独立复现成功率、每成功任务美元、官方榜单分数与持续运行稳定性**。应将Run、Trajectory、版本与环境Digest、失败原因、数据缓存、独立评测、回滚记录长期保存；区分环境优化的收益与模型/优化算法自身收益。

## AI与RSI

### RSI / 自进化重点

**1. The Resolution Hypothesis：识别真实提升可能比生成新候选更困难。** 11月17日论文分析七类Agent演化方法、六种模型和千万级LLM调用；作者报告改善候选存在，但噪声评估对好/坏候选的区分在一些设置中接近随机。**类别：Evaluator/Harness；新意：**将候选生成能力与改进检测分辨率分离。**可执行：**多种子、成对隐藏集评测，测False Acceptance Rate、旧任务回归率、提升置信区间及每一次真实提升的成本；结果尚未独立复现。[arXiv:2611.23068](https://arxiv.org/abs/2611.23068)

**2. OpenAI Research acceleration：把自动化研发量与真实能力输出分开。** 11月18日发布内部科研Agent数据，监控训练运行、部署推理代码等不同环节成功率悬殊。**类别：Model R&D/RSI Measurement；新意：**将任务能力、实际研发流程、研究产出放在不同层级测量，而非只看实验数。**可执行：**分别汇报有效实验率、每美元带来的Baseline提升、后续模型/优化器自身能力变化；内部报告不等于开放可复现Bench。[OpenAI原文](https://openai.com/index/research-acceleration-jagged-frontier/)

**3. Harnesses That Improve Themselves：模块化补丁与回归门控优于全量重写。** 11月17日论文把Harness拆为状态/上下文、控制、工具接口、验证恢复模块，并提出诊断→补丁→验证→部署的闭环；作者报告SWE-bench Lite上的验证效果。**类别：Harness/Tool/Verification；新意：**更新范围更可归因且易回滚。**可执行：**优先针对超时、重复循环、工具故障、提前结束四类Bad Case做模块级与整体重写的固定预算对照，另用独立隐藏集避免评测器污染。[arXiv:2611.22299](https://arxiv.org/abs/2611.22299)

**4. Do LLM Agents Still Need to Be Told How to Self-Improve?：让Agent探索自己的学习机制。** 11月17日论文给冻结权重模型提供工具、预算与可编辑文档，观察它在游戏任务中自主形成自我训练/课程式策略及部分迁移。**类别：Memory/Task/早期Recursive RSI探索；新意：**不预设固定Optimizer流程。**可执行：**比较固定和自主Optimizer在同预算、多轮未知任务上的改进效率；由于权重冻结和场景受限，不能宣称已经验证真正递归模型能力提升。[arXiv:2611.23219](https://arxiv.org/abs/2611.23219)

**RSI 今日结论：** 最值得深入的是Resolution Hypothesis：只有可靠识别和积累改进，优化器生成更多候选才有意义。优先落地独立评测、多随机种子和错误更新门控，再研究Harness及优化策略自修改。

### 主要风险与阈值
- 市场价格虽已降，但**没有通过当前证据确认的Level 3/4/5买点**。对旧Fair Value应按新增会计调查、AI Capex现金流、盈利下修和信用风险复核；假设2027E EPS较当前共识连续两次下修或累计下修超过10%、ROIC低于估计资本成本、FCF连续两个季度偏离Base路径，作为**研究触发器（假设阈值、非客观保证）**。
