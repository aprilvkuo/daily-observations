### 数据口径、初筛方法与评分原则
本期行情初筛覆盖A股20只、港股19只、美股20只，共59只跨行业候选，之后分别提出10只研究观察名单。初筛不等于完成59家公司逐一的财报、法律事件与Forward估值审计；对证据不足的股票，明确保持不确定状态。A股、港股、美股均以2026-11-20正式日线收盘价列示，2026-11-21周六休市。
统一评分框架：质量20%、Forward估值/安全边际20%、常态盈利或FCF增长20%、资本效率15%、资产负债表/盈利稳定性10%、分红回购5%、最新方向10%，另扣治理、监管、周期、杠杆及集中度风险。由于Forward数据缺失，不对40个榜单位置宣称已完成可比加权打分，更不能根据排名直接下单。
**核心公式**：Forward Normalized PE=收盘价/未来12个月正常化每股盈利；FCF Yield=未来12个月可归属股权的正常化FCF/股权市值；MOS=(Base Fair Value-现价)/Base Fair Value；预期CAGR应结合正常化FCF/EPS增长、股息回购及期末可持续估值。银行另看Forward PB、ROE、NIM、NPL和拨备；保险看P/EV与NBV；资源看中周期商品价格，不能用现货高景气利润永久化。Fact、Calculation与Assumption不能混用。
**信号定义**：A/B/C/D基本面等级是定性信息完整度与风险判断，不能代替财报审计。三灯依次为价格、基本面、估值；🟡表示待核，🔴表示暂停或明显负向风险，🟢仅表示已经验证的有利条件。Level 5 Strong Buy、Level 4 Buy、Level 3 Accumulate、Level 2 Hold/观察、Level 1 Avoid/Revalue。本期没有经验证的Level 4/5买入信号。

### RSI / 自进化重点（不占今日总览名额）

**2.《The Resolution Hypothesis》：优化循环可能卡在Evaluator而非候选生成。** arXiv提交2026-11-17；分类：**Evaluator / Harness / Memory**。作者对7种演化方法、6种模型及超过千万次模型调用的分析指出，优化器生成有益候选并不罕见，噪声评测却可能无法把它们与有害候选区分。新意在于定量揭示选择误差跨轮累积。**可执行**：固定候选池、多随机种子、可信隐藏集、成对比较、错误接受率、退化率、bootstrap置信区间；先提升选择分辨率，再扩展候选搜索。作者结果未独立复现。来源：https://arxiv.org/abs/2611.23068 。
**3.《Do LLM Agents Still Need to Be Told How to Self-Improve?》：让Agent自主组织上下文学习策略。** arXiv提交2026-11-17；分类：**Memory / Task / 早期Recursive RSI探索**。研究让权重冻结的Agent自主使用算力、工具及文本记忆形成自我学习机制，并在游戏任务中测试跨环境转移。新意不是让模型自动改权重，而是观察Agent能否发明改进流程。**可执行**：对照固定优化循环与自由优化循环，固定预算及可用工具，比较多轮学习曲线、跨任务泛化和下一轮优化效率。属于基于上下文的自学习，尚不能证明无限递归自我提升。来源：https://arxiv.org/abs/2611.23219 。
**4.《Harnesses That Improve Themselves》：模块级更新比整个Harness重写更可审计。** arXiv提交2026-11-17；分类：**Harness / Tool / Verification**。框架划分上下文/状态、控制、工具接口、验证恢复四模块，给出诊断、补丁、验证、部署的闭环，并讨论评测污染和回滚。新意是将变更控制与回归验证作为自优化系统的一部分。**可执行**：将超时、工具重试、上下文膨胀、提前退出四类Bad Case分别做模块实验，记录修改影响、跨任务稳定性与旧能力非劣。属于Harness自优化，是否改善优化器自身能力需另测。来源：https://arxiv.org/abs/2611.22299 。
